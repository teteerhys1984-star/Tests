# اختبار الوحدة الأولى — الرياضيات للصف الخامس الأساسي

اختبار إلكتروني تفاعلي عربي (RTL) يغطي الوحدة الأولى كاملة: **30 سؤالاً رئيسياً، مجموع العلامات 100**، موزعة على الدروس الثمانية وفق المخطط المطلوب. المحتوى مستخرج من مستودع المنهاج:
`https://github.com/teteerhys1984-star/Interactive-Mathematics-Grade5` (أرقام الصفحات: شبكة الإحداثيات ص 3–4، التمثيلات البيانية ص 7–9، الأعداد الطبيعية ص 10–14، التقريب ص 15–18، الجمع والطرح ص 19–22، الزوايا ص 23–30، متوازي الأضلاع ص 31–35، المعيّن ص 36–39).

## التشغيل

```bash
npm install
npm run dev        # تطوير
npm test           # اختبارات الوحدات (منطق التصحيح والحساب ومحرر الكسور وبنك الأسئلة)
npx tsc --noEmit   # فحص الأنواع
npm run build      # بناء ملف واحد dist/index.html (الخطوط والأصوات و KaTeX مدمجة محلياً)
```

## البنية

- `src/data/` — الدروس (`lessons.ts`) وبنك الأسئلة (`bank-a..d.ts`) وترتيب العرض (`index.ts`). ترتيب الأسئلة مختلط عمداً وليس حسب الدروس.
- `src/lib/expression.ts` — وثيقة الإجابة الرياضية، والمقيّم الحسابي، وفحص الصيغة الموسّعة.
- `src/lib/mathEditor.ts` — محرر الكسور الحقيقي (بسط ومقام في خانتين منفصلتين، تنقل بـ ▲ ▼ ◀ ▶).
- `src/lib/grading.ts` — التصحيح، والعلامات الجزئية للبنود المتعددة (الترتيب، المطابقة، ملء الفراغات).
- `src/lib/geometry.ts` — قراءة المنقلة، والتسامح في الرسم، ومتوازي الأضلاع والمعيّن.
- `src/lib/attempt.ts` — حفظ المحاولة في `localStorage`، والمؤقت بالطوابع الزمنية الحقيقية، والنتائج.
- `src/lib/report.ts` — تقرير TXT بترميز UTF-8 (BOM) يتضمن اسم الطالبة في اسم الملف.
- `src/components/Figures.tsx` — الشبكة، والتمثيل البياني، ومستقيم الأعداد، والمنقلة، والزوايا، والأشكال بـ SVG ذي نسب ثابتة.
- `src/screens/` — البداية، والاختبار، والنتائج، ولوحة المعلم.

## قواعد مهمة

- **الإحداثيات:** الأول أفقي والثاني شاقولي، ولا يُعكس الزوج أبداً.
- **التسليم:** زر «تسليم الاختبار» معطّل حتى تُجاب كل الفروع، ويُسلَّم فوراً بلا أي نافذة تأكيد.
- **المؤقت:** يبدأ فقط بعد «بدء الاختبار»، ويُحسب من وقت البدء الحقيقي فيستمر بعد التحديث.
- **الحفظ:** كل إجابة تُحفظ فوراً؛ تحديث الصفحة يستعيد المحاولة نفسها والوقت والإجابات.
- **الإجابات:** لا تُعرض أي إجابة أو تلميح أثناء المحاولة.
