# واجهة الفهرس (الصفحة الرئيسية)

هذا المجلد يحتوي على **تصميم ومولّد الصفحة الرئيسية** فقط. لا يغيّر أي شيء في
مجلدات الاختبارات: لا منطق تصحيح، ولا `EXAM_ID`، ولا روابط منشورة، ولا نظام
الإرسال إلى Google Sheets.

```
landing/
├── template.html        # التصميم كاملًا: HTML + CSS + JavaScript (ملف واحد، بلا اعتماديات)
├── generate.py          # يقرأ المجلدات المنشورة في _site ويبني _site/index.html
├── exams.json           # (اختياري) تصنيف يدوي لتجاوز التصنيف التلقائي
├── tests/test_generate.py   # اختبارات قواعد الظهور والروابط
└── scripts/build-exams.sh   # محاكاة خطوة بناء الاختبارات في النشر
```

## تجربة الاستخدام: ثلاث خطوات

```
الصفوف  →  المواد  →  الاختبارات
```

* **الصفوف:** تسع بطاقات ملوّنة، لكل صف لونه ورقمه (بالأرقام الإنجليزية 1–9)، وعدد المواد
  والاختبارات المتاحة فيه، ونقاط ملوّنة توضّح المواد التي فيها اختبارات.
* **المواد:** بطاقات أكبر مع أيقونة SVG لكل مادة (كتاب، فرجار، ذرّة، دورق،
  حوار) ولون خاص بها. المواد التي لا اختبارات فيها تظهر بوضع «قريبًا».
* **الاختبارات:** بطاقات واضحة فيها عنوان الاختبار ومساره وزر «ابدأ».

لا توجد قوائم منسدلة ولا أكورديون: الانتقال بين الخطوات يتم بمشاهدة كاملة مع
حركة خفيفة، ومسار تنقّل (فتات الخبز) أعلى الصفحة، وروابط قابلة للمشاركة:

```
/#g7             ← مشهد مواد الصف السابع
/#g8/physics     ← مشهد اختبارات فيزياء الصف الثامن
```

خصائص أخرى: بحث فوري يتجاهل التشكيل واختلاف الألف/الياء/التاء، زر رجوع في كل
مشهد، دعم أزرار المتصفح (الرجوع/التقدّم)، اختصار `/` للبحث و`Escape` للرجوع،
تخطيط RTL كامل، واستجابة كاملة للهاتف والكمبيوتر.

الصفحة مكتفية بذاتها تمامًا: **لا صور، لا خطوط من الإنترنت، لا مكتبات
خارجية، ولا أي طلب شبكة** — كل الأيقونات رموز SVG مضمَّنة في الملف.

## الأرقام

كل الأرقام الظاهرة في الواجهة إنجليزية (0–9): أرقام الصفوف، ترقيم الاختبارات،
أعداد المواد والاختبارات، الخطوات، وعدد نتائج البحث. التحويل يتم عند العرض فقط
(الدالة `num` في `generate.py`)، وأي رقم عربي-هندي يرد في عنوان اختبار يُعرض
بالإنجليزية من دون تغيير الاختبار نفسه أو رابطه أو معرّفه.

## الطائرة الورقية (سماء الواجهة)

طبقة `.sky` داخل الواجهة العلوية: طائرة ورقية تعبر الصفحة بهدوء وخلفها مسار
منقّط، مع غيوم ونجوم خافتة. كلها SVG و CSS داخل `template.html` (بلا صور ولا
مكتبات ولا JavaScript)، تتحرك بـ `transform` فقط، خلف المحتوى
(`pointer-events: none`) فلا تحجب نصًّا ولا زرًّا، وتتوقف تمامًا مع
`prefers-reduced-motion`.

## بيانات المهندس

اسم المهندس ورقمه يظهران في الشريط العلوي وفي بطاقة التذييل (في نهاية الصفحة،
غير عائمة). الرقم وشعار WhatsApp رابط واحد إلى `https://wa.me/963930215022`
وهو الرابط الخارجي الوحيد في الصفحة (رابط تنقّل، لا مورد يُحمَّل). لتعديل
البيانات: ابحث عن `wa.me` في `template.html`.

## قاعدة ظهور المواد

مضبوطة في مكان واحد في أعلى `generate.py`:

| المادة | الصفوف التي تظهر فيها |
| --- | --- |
| اللغة العربية | 1 – 9 |
| الرياضيات | 1 – 9 |
| اللغة الإنجليزية | 1 – 9 |
| الفيزياء | 7 – 9 فقط |
| الكيمياء | 7 – 9 فقط |

> لا تظهر بطاقة الفيزياء أو الكيمياء إطلاقًا في الصفوف من الأول إلى السادس.
> لتعديل القاعدة: غيّر الصفوف في قائمة `SUBJECTS` في أعلى `generate.py` فقط.

## كيف يُصنَّف اختبار جديد؟

كما كان سابقًا: يقرأ المولّد `<title>` من `dist/index.html` لكل مجلد منشور،
ويستخرج الصف والمادة (اسم المجلد يُستخدم احتياطًا)، ثم يضع الاختبار في مكانه
تلقائيًا. **لا حاجة إلى أي تعديل يدوي عند إضافة اختبار جديد.**

إن كان عنوان اختبار لا يكفي لتصنيفه، أضف استثناءً يدويًا في `landing/exams.json`:

```json
{
  "overrides": {
    "grade7-physics-exam": { "grade": 7, "subject": "physics", "title": "اختبار الفيزياء — الصف السابع" }
  }
}
```

وإن صُنّف اختبار في مادة لا تُعرض في صفّه، يطبع المولّد
`::warning::` في سجل النشر بدل إخفائه بصمت.

## التشغيل والتحقق محليًا

```bash
# 1) بناء كل الاختبارات وتجميعها في _site (محاكاة خطوة النشر)
bash landing/scripts/build-exams.sh

# 2) توليد الصفحة الرئيسية
python3 landing/generate.py _site

# 3) اختبارات قواعد الظهور والروابط
python3 landing/tests/test_generate.py

# 4) فحص الموقع الناتج (الروابط، EXAM_ID، قاعدة المواد، الأرقام، بيانات المهندس)
python3 landing/scripts/verify-site.py _site

# 5) معاينة محلية
python3 -m http.server 8080 --directory _site
```

## الملفات التي يلمسها النشر

`.github/workflows/deploy.yml` لم يتغيّر إلا في خطوة واحدة: خطوة
«Generate landing page» صارت تستدعي `python3 landing/generate.py _site`
بدل سكربت بايثون مضمَّن داخل ملف YAML. خطوات بناء الاختبارات والنشر نفسها
لم تتغيّر.
