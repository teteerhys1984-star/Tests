## 4. نتائج الاختبارات الآلية

جميع الأوامر نُفِّذت من داخل مجلد الاختبار.

### 4-أ. TypeScript

```
npx tsc --noEmit
# الخروج: 0 — بلا أخطاء
```

ملاحظة نطاق: `tsconfig.json` يشمل `src` و`vite.config.ts` فقط (كما في كل اختبارات المنصة السابقة)؛
ملفات `tests/*.tsx` تُبنى بـ esbuild وتُشغَّل بـ node، وليست ضمن فحص `tsc`، لتجنّب الحاجة إلى
`@types/jsdom` في حزمة النشر. ملفات الاختبار نفسها مرّت بلا أخطاء تشغيل أو تحويل.

### 4-ب. اختبارات المشروع — `npm test` (node + esbuild + jsdom)

```

━━━ المحتوى والعلامات والحفظ (tests/content.test.ts) ━━━     ✅

```

تفصيل ما تغطّيه:

- **المحتوى:** 10 أسئلة، 44 فرعاً، لا فرع بلا مفتاح ولا مفتاح لفرع غير موجود، كل سؤال = 10، المجموع = 100،
  تطابق نوع المفتاح مع نوع الفرع، معرّفات خيارات متسلسلة، رسوم أربعة، معرّفات التخزين معزولة.
- **التصحيح:** الإجابة الصحيحة الكاملة لكل فرع من أصل 44 ← العلامة كاملة (44/44)؛ الفارغ ← 0؛ كل خيار خاطئ ← 0؛
  الوحدة الخاطئة في العدد ← حسم علامة واحدة؛ بلا وحدة ← العلامة كاملة؛ التصحيح الجزئي للإجابات القصيرة بمعيار واحد؛
  صيغ الثقل المكافئة (`w=mg` · `m=w/g` · `g=w/m` · `mg=w`) ← كاملة، وغير المكافئة ← 0؛ اختبار كامل 100/100 و0/0.
- **التقرير:** BOM، CRLF، فواصل 78 خانة، عناوين «السؤال N —»، 44 سطر فرع، «لم تُجب»، اجتياز `validateReport`،
  ورفض تقرير مُفسَد.
- **الحفظ:** استعادة صحيحة، رفض محاولة اختبار آخر، رفض `questionIndex` خارج النطاق، رفض JSON تالف، رفض تسليم قبل البدء.
- **الإرسال (Mock Fetch فقط):** الحقول الاثنا عشر بالترتيب نفسه، `text/plain;charset=utf-8`، `ok:true` و`duplicate:true`،
  الفشل بعد 3 محاولات بفواصل 2000/5000 مللي ثانية، المهلة 30 ثانية، الحفظ المعلّق، إعادة الإرسال اليدوي،
  `retryPending` عند التحميل (ولا يمسّ معلّقات اختبار آخر)، ولا كتابة لبيانات الطالب في `console`.
- **سير العمل (jsdom):** ترحيب ← اسم ← 10 أسئلة ← مراجعة ← تسليم ← نتيجة 100/100 ← تنزيل TXT تلقائي ← إرسال ناجح؛
  ثم إعادة تحميل ← استعادة المحاولة ← فشل الإرسال (3 محاولات + حفظ معلّق) ← «إعادة إرسال» ← نجاح؛
  بوابة المعلّم (كلمة خاطئة تُرفض / `somer173` تفتح)؛ عزل التخزين؛ محاولة جديدة؛ عدم كشف أي إجابة قبل التسليم.

## 5. ما لم يُتحقَّق منه (حدود صريحة)

1. **لا فحص بصري في متصفح حقيقي.** لا توجد متصفحات (Chromium/Playwright) في بيئة العمل، فلم يُجرَ فحص
   `tests/visual-smoke.mjs` ولم تُلتقط صور للشاشات. تحقّق الواجهة كان عبر DOM فقط (jsdom) وعبر بناء الإنتاج،
   وليس بديلاً عن فحص بصري على جوال وسطح مكتب.
2. **لا إرسال حقيقي إلى Google Sheets.** كل اختبارات الإرسال استعملت Mock Fetch؛ لم يُرسَل أي طالب حقيقي،
   ولم يُثبَت أن Apps Script يستقبل هذه الحمولة فعلياً من الموقع المنشور. يلزم فتح الموقع المنشور وتسليم اختبار
   تجريبي واحد للتأكيد. الرابط والرمز والقيم نفسها المستعملة في `grade5-math-unit1` لم تتغيّر.
3. **لا فحص على أجهزة/متصفحات حقيقية** (Safari/iOS تحديداً) — تنزيل TXT ومنع التنزيل التلقائي معروض ببديل
   («تنزيل التقرير»)، لكن ذلك لم يُختبر في تلك المتصفحات.
4. **لا تدقيق لغوي/علمي خارج المقارنة الحرفية مع المصدر**: النصوص نُقلت كما هي، ولم يُفترض أن كل صياغة في
   المصدر خالية من الخطأ الأسلوبي؛ لم تُعدّل لأن تعليمات العمل تقتصر على الأخطاء المؤكّدة.
5. **حماية المعلّم في جهة العميل فقط** — حاجز وصول بسيط لا مصادقة؛ موثّق داخل الصفحة نفسها.
