# قواعد اللغة والإملاء للوحدة الأولى وأول درسين من الوحدة الثانية — نموذج ثالث

اختبار رسمي تفاعلي مستقل (**نموذج ثالث**) للصف الخامس الأساسي في مادة **اللغة العربية** (**قواعد اللغة والإملاء فقط**)، يغطي:
- **الوحدة الأولى كاملة:** السمكة الذهبية (ص 8–9)، بالرأي والرأي الآخر (ص 17–20)، لغتي (ص 28–32).
- **الوحدة الثانية (أول درسين):** مخترع من بلادي (ص 44–46)، الذكاء الاصطناعي (ص 54–56).

## الهوية والاستقلالية
- **المجلد المنشور ومعرّف الاختبار (`EXAM_ID`):** `grade5-arabic-grammar-spelling-u1-u2-l1l2-pattern3`
- **مستقل بالكامل** عن النموذج الأول (`grade5-arabic-grammar-spelling-u1-u2-l1l2`) والنموذج الثاني (`grade5-arabic-grammar-spelling-u1-u2-l1l2-pattern2`) في مفاتيح `localStorage` ومعرفات المحاولات وسجلّات الإرسال المعلّقة والمرسلة.

## التوزيع المؤكد
- **30 سؤالًا رئيسيًا** (6 أسئلة لكل درس × 5 دروس).
- **15 سؤال قواعد لغة (50 درجة) + 15 سؤال إملاء (50 درجة)**.
- **70 فرعًا** قابلًا للتصحيح المستقل (14 فرعًا و20 درجة لكل درس).
- **100 درجة** بالضبط.

## التشغيل والتحقق
```bash
npm ci
npm test           # تشغيل اختبارات مطابقة الـBaseline والإرسال الوهمي والاستقلالية
npm run typecheck  # فحص الأنواع (tsc --noEmit)
npm run build      # بناء ملف HTML واحد مكتفٍ بذاته في dist/index.html
```

## الميزات والخصوصية
- اسم الطالبة إلزامي، والمؤقت التصاعدي (`HH:MM:SS`) يبدأ عند الضغط على «بدء الاختبار» ويُحفظ تلقائيًا في `localStorage` بمعزل عن بقية النماذج.
- لا تظهر الإجابات أو الدرجات أثناء الاختبار؛ التسليم فوري بزر «تسليم الاختبار» بعد إجابة الفروع جميعها.
- إرسال النتيجة إلى المعلّمة عبر Google Sheets وفق عقد المنصة المعتمد (3 محاولات، منع تكرار وتزامن، حفظ محلي للمحاولات المعلّقة وإعادة إرسالها تلقائيًا عند الفتح، وزر مستقل لإعادة الإرسال دون حجب النتيجة أو التقرير عند فشل الشبكة).
- تقرير TXT عربي UTF-8 (مع BOM) قابل للتنزيل، ومفتاح معلم بكلمة مرور `somer173` (حاجز واجهة تعليمي في المتصفح فقط).
- راجع [`AUDIT.md`](AUDIT.md) لتفاصيل خط الأساس (Baseline) والتدقيق والإصلاحات الموثقة.
