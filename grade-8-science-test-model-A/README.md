# اختبار الصف الثامن — الفيزياء والكيمياء · النموذج (أ)

امتحان تفاعلي كامل مبني بـ **React + TypeScript + Vite + Tailwind CSS v4**، بواجهة عربية RTL
موجّهة للجوال أولاً. 24 سؤالاً رئيسياً متبادلاً (12 فيزياء + 12 كيمياء)، 100 درجة (50 + 50).

## التشغيل

```bash
npm install
npm run dev        # التطوير
npm run build      # بناء الإنتاج إلى dist/index.html (ملف واحد)
npm run preview    # معاينة الإنتاج
npx tsc --noEmit   # فحص أنواع TypeScript
npx vitest run     # الاختبارات الوحدوية
```

## المراحل

1. **شاشة البداية** — اسم الطالب إلزامي، تعليمات، كتم/تشغيل الصوت. المؤقّت لا يبدأ إلا بضغط
   «بدء الاختبار».
2. **شاشة الاختبار** — سؤال واحد في كل مرة، مؤقّت عدّ تصاعدي `HH:MM:SS` قائم على طابع زمني،
   حفظ تلقائي في `localStorage`، استعادة نفس المحاولة بعد التحديث، لا تغذية راجعة ولا حلول.
3. **النتيجة** — الاسم، 50 فيزياء، 50 كيمياء، 100 المجموع، إجابة الطالب مقابل الإجابة
   النموذجية، درجات كل مطلب، معايير التصحيح، الحل العلمي، ومصدر السؤال وصفحته، مع تنزيل
   تقرير TXT (UTF-8) باسم الطالب + نسخة احتياطية.
4. **منطقة المعلّم** — بكلمة المرور `somer173` (حاجز رؤية فقط)، تظهر من التذييل ولا تظهر
   أثناء وجود محاولة اختبار جارية.
