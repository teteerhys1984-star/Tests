# اختبار الفيزياء للصف الثامن — الاختبار الثاني

هذا اختبار مستقل عن `grade8-physics-unit1-l1l2`، ومعرّفه ومسار نشره هما `grade8-physics-exam-2`. محتواه الأصلي هو الوحدة الأولى «الحركة والقوى»: الدرس الأول «القوى المتلاقية» (ص 55–62)، والدرس الثاني «القوى المتوازية» (ص 63–70).

- 15 سؤالاً رئيسياً، و41 فرعاً، و100 درجة: 45 للدرس الأول و55 للدرس الثاني.
- الأنواع: 20 اختياراً من متعدد، و3 اختيار متعدد، وترتيب واحد، و4 صح/خطأ، و11 عددياً، ومطابقتان.
- الصفحة الأصلية HTML وCSS وJavaScript دون إطار عمل في وقت التشغيل؛ الرسوم SVG والصوتان WAV مضمّنة. يستعمل المشروع Vite لبناء ملف HTML مستقل واحد يناسب آلية النشر القائمة.

## التشغيل والبناء

```bash
npm ci
npm test
npm run build
npm run dev
```

ينتج البناء `dist/index.html` مكتفياً بنفسه. تجمع `scripts/sync-exam.mjs` الأجزاء الموجودة في `exam-src/`، بما فيها الصوتان الأصليان، داخل ملفات HTML الثلاثة المتطابقة. شغّل `npm run sync` بعد تعديل المصادر؛ ويُشغّل التجميع تلقائياً قبل البناء أو خادم التطوير. يتحقق `npm test` من عدم اختلاف الملفات المجمّعة عن مصادرها.

أُخذت المصادر البصرية وبنك الأسئلة من `index.html` الأصلي الذي كان يعمل فعلياً؛ كانت النسخ المفككة الأصلية أقدم في بضعة مواضع من التنسيق والرسوم. لم يُغيَّر التصحيح أو محتوى الأسئلة. تبقى نسخة الأصل غير المعدّلة مضغوطة في `tests/fixtures/original.html.gz` للمقارنة الفعلية، ولا تُنشر مع الصفحة.

## الإرسال والخصوصية

عند التسليم تُعرض النتيجة ويُنزّل التقرير دون انتظار الشبكة. تُرسل النتيجة والإجابات ونص التقرير إلى المعلّم بعقد `grade5-math-unit1` نفسه. التقدير في `summary` المرسلة فقط، ولا يُضاف إلى صفحة الطالب أو تقريره.

يُحفظ الطلب قبل إرساله تحت `pending:grade8-physics-exam-2:<attemptId>`، ويُحذف بعد تأكيد الخادم فقط. تُعاد المحاولة ثلاث مرات بانتظار ثانيتين ثم خمس ثوانٍ، ومهلة 30 ثانية لكل طلب؛ ويُعاد إرسال المعلّق عند فتح الصفحة، مع زر مستقل لإعادة الإرسال. لا تُطبع بيانات الطالب في وحدة التحكّم. تُنسّق Web Locks، أو IndexedDB عند عدم توفرها، إرسال المحاولة بين الألسنة؛ ويُحفظ إيصال بلا بيانات الطالب لمنع إعادة إرسال ما تأكّد وصوله. عند تعطيل التخزين يُنبّه الطالب إلى الاحتفاظ بالتقرير، لأن الاستعادة بعد إغلاق الصفحة لا يمكن ضمانها.

## التحقق

تقارن الاختبارات بنك الأسئلة والرسومات والتصميم والتصحيح والتقرير مع HTML الأصلي في الحالات الصحيحة والخاطئة والفارغة والمختلطة والجزئية، وتجرّب جميع الأنواع. كما تختبر عقد الإرسال والإخفاق والمهلة والتخزين والاستعادة والتزامن ببدائل شبكة محلية فقط؛ لا تتصل الاختبارات بـ Google Sheets. سُجّل من الأصل: 100 للإجابات الصحيحة، و0 للفارغة، و96.25 للحالة المختلطة المرجعية، و2.25 لخطة الإجابات الخاطئة المرجعية بسبب الدرجات الجزئية للاختيار المتعدد.

حُفظ شكل العقد والتقديرات في `tests/fixtures/grade5-contract.json` بعد توليده من دوال المرجع الفعلية. يمكن إعادة مقارنته مباشرة بالمرجع المجاور بعد تثبيت اعتمادات `grade5-math-unit1` عبر `npm ci` ثم تشغيل `npm run test:reference` هنا؛ هذا الفحص الإضافي اختياري، أما `npm test` والتطبيق فيعملان دون الاعتماد على مجلد آخر.
