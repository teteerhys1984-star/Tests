# اختبار الفيزياء — الصف السابع — الوحدة الأولى: الحركة والسكون

اختبار إلكتروني تفاعلي عربي (RTL) للصف السابع، مبنيّ على محتوى الكتاب المدرسي للوحدة الأولى
(الحركة والتحريك)، الدرس الأول «الحركة والسكون» — صفحات الكتاب 3–16 فقط.

- معرّف الاختبار: `EXAM_ID = grade7-physics-exam` (مطابق لاسم المجلد).
- المحتوى: **12 سؤالاً رئيسياً · 49 جزءاً مقوّماً · 100 علامة** — لم يتغيّر أي سؤال أو إجابة
  أو قاعدة تصحيح أو علامة عن النسخة الأصلية المرفوعة في المستودع.
- التصحيح: تلقائي بالكامل داخل المتصفح (نفس دالة `gradeExam` الأصلية).
- الإرسال: نفس عقد الاختبار المرجعي `grade5-math-unit1` إلى تطبيق Google Apps Script نفسه.

## الصفحات

1. الترحيب + إدخال اسم الطالبة.
2. الأسئلة (سؤال واحد في كل شاشة، لوحة تنقّل، عدّاد تصاعدي HH:MM:SS، شريط تقدّم).
3. «مراجعة الإجابات» قبل التسليم (التسليم معطّل حتى تُجاب كل الأجزاء).
4. صفحة النتيجة: الدرجة والنسبة والمراجعة، وحالة إرسال النتيجة إلى المعلّم.
5. تقرير TXT يُنزَّل تلقائياً عند التسليم، ويبقى قابلاً للتنزيل من صفحة النتيجة.
6. «منطقة المعلم» بمفتاح الإجابات (بوابة شكلية بكلمة مرور، كما في الأصل).

## الإرسال إلى المعلّم (Google Sheets)

- `SHEETS_URL` و`SHEETS_TOKEN` مأخوذان حرفياً من `grade5-math-unit1/src/config.ts`.
- `POST` بنوع `text/plain;charset=utf-8`، و3 محاولات بفاصلين 2 ثم 5 ثوانٍ، ومهلة 30 ثانية للمحاولة.
- عند فشل كل المحاولات تُحفظ الحمولة في `localStorage` تحت `pending:<EXAM_ID>:<attemptId>`،
  وتُعاد بصمت عند فتح الاختبار لاحقاً، ولا تُرسَل المحاولة نفسها مرّتين (لا بالتوازي ولا بالتكرار).
- صفحة النتيجة تعرض دائماً: «جارٍ إرسال النتيجة…» ثم «تم إرسال نتيجتك إلى معلّمك ✓»،
  أو رسالة فشل واضحة مع زر مستقل «إعادة إرسال النتيجة» (منفصل عن «محاولة جديدة»).
- حمولة الإرسال تطابق عقد المرجع حرفياً:

  `token, attemptId, examId, examTitle, studentName, startAt, submitAt, elapsedSec, summary, lessons, details, reportText`

  مع `summary.gradeLabel` من سلّم التقدير نفسه في `grade5-math-unit1`
  (يُرسَل للمعلّم فقط: لا يظهر للطالبة، ولا يُكتب في تقرير TXT).
- `lessons` = الأسئلة الرئيسية الاثنا عشر بعلاماتها (هذا الاختبار لا يحوي «دروساً» مرقّمة مثل المرجع).

## الخصوصية

كان سطر في تقرير TXT يقول إن التقرير «لم يُرسل إلى أي جهة خارجية»؛ أُعيدت صياغته ليصبح صحيحاً:

> وُلّد هذا التقرير محلياً في المتصفح عند التسليم، وتُرسَل النتيجة والإجابات إلى المعلّم إلكترونياً.

وشاشة الترحيب تقول صراحةً إن النتيجة والإجابات تُرسَل إلى المعلّم عند التسليم.
لا توجد في التطبيق أي ادعاءات عن التشفير أو السرية.

## السكربتات

```bash
npm ci
npm test            # التصحيح (مقابل مرجع النسخة الأصلية) + الحمولة + الإرسال + سير العمل، بلا شبكة حقيقية
npm run build       # ناتج single-file في dist/index.html
node scripts/validate-exam.mjs   # تحقق بنيوي من الأسئلة والعلامات (من الأصل)
node scripts/e2e-test.mjs        # فحص في متصفح حقيقي بعد البناء — يحتاج playwright (غير مثبّت كاعتماد)
```

> `npm test` يستعمل خادماً بديلاً على `127.0.0.1` و`fetch` وهمياً وساعة وهمية؛ **لا يجري أي اتصال
> حقيقي بـ Google Apps Script** ولا يُكتب شيء في Google Sheets أثناء الاختبارات.

## كيف يُثبت أن التصحيح لم يتغيّر

- `tests/fixtures/grading-golden.json` سُجّل من النسخة الأصلية للاختبار **قبل** أي تعديل
  (253 ورقة إجابة ثابتة: صحيحة كاملة، فارغة، خاطئة كاملة، لكل جزء، مع علامات جزئية، وبلا إجابات، ومختلطة).
- `tests/grading.test.ts` يصحّح الأوراق نفسها بالكود الحالي ويشترط تطابق كل علامة وكل حالة
  وكل نص وكل تقرير TXT، ويشترط أن يكون `src/exam-data.js` (بنك الأسئلة) مطابقاً حرفياً للأصل،
  وأن `src/report.js` لا يختلف عنه إلا في تعديلين مسجّلين في `tests/golden.ts`.
- لإعادة تسجيل المرجع من النسخة الأصلية:

  ```bash
  rm -rf /tmp/orig && mkdir -p /tmp/orig
  git archive 8427a6f1d84b3604998a68c00f06768ea5c1398e grade-7-physics-exam | tar -x -C /tmp/orig
  node tests/run.mjs make-golden --src /tmp/orig/grade-7-physics-exam/src
  ```
