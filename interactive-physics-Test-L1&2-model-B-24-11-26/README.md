# اختبار الفيزياء — الصف السابع | النموذج B

مشروع React وTypeScript وVite لاختبار عربي تفاعلي مكوّن من عشرة أسئلة رئيسية، عشر علامات لكل سؤال، ومجموع 100 علامة. يعمل محلياً في المتصفح دون خادم أو حسابات.

## التشغيل والفحص

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev
npm run typecheck
npm test
npm run build
npm run preview
```

للفحص الحقيقي في Chromium على عروض 320 و375 و390 و430 و768 و1280 بكسل، ثبّت المتصفح مرة واحدة بـ `npx playwright install chromium` ثم شغّل `npm run test:ui`. على الأنظمة التي تفتقر إلى مكتبات المتصفح، يلزم أيضاً `npx playwright install-deps chromium`. يفحص هذا الاختبار الرسوم وKaTeX والتمرير الأفقي واستعادة المحاولة والتسليم والتقرير ومنطقة المعلم.

يبني `npm run build` نسخة جاهزة في `dist/`. يبدأ المؤقت عند اختيار **بدء الاختبار** فقط، وتُحفظ المحاولة والإجابات والسؤال الحالي ووقت البدء وحالة التسليم في `localStorage`. بعد التسليم تُعرض الدرجة والتصحيح التفصيلي فوراً، ويمكن تنزيل تقرير TXT محلي بترميز UTF-8. لا تُفتح محاولة جديدة تلقائياً عند تحديث الصفحة.

## الحدود المنهجية

المصدر الوحيد للمفاهيم هو مستودع [Physics_Chemistry_7th](https://github.com/calesteer-create/Physics_Chemistry_7th):

- [الدرس الأول: الحركة والسكون](https://github.com/calesteer-create/Physics_Chemistry_7th/blob/main/src/content/lessons/unit1/motion-and-rest.ts)، صفحات الكتاب 3–16.
- [الدرس الثاني: القوة والحركة](https://github.com/calesteer-create/Physics_Chemistry_7th/blob/main/src/content/lessons/unit1/force-and-motion.ts)، صفحات الكتاب 17–28.
- تمت مراجعة `src/content/unit1-assessment.ts` و`src/content/quiz-bank.ts` و`src/content/registry.ts` ورسوم الدرسين في المستودع المرجعي لضبط التغطية وتجنب تكرار المواقف والأرقام المباشرة. لا توجد أسئلة عن بقية دروس الوحدة.

الأسئلة مستقلة: رحلة جري متعددة المراحل، شعاع قوة مقسّم، مصعد ومرجعان، جسم على الأرض والقمر، مخطط حركة مركبة، ثلاثة آثار للقوة، مسار متصل مختلط، عداد رقمي، استخراج كتلة من ثقل، واستنتاج تكاملي. صياغة المعطيات والأمثلة والرسوم أصلية لهذا النموذج.

## تنظيم الملفات

- `src/data/questions.ts`: نص الأسئلة والاختيارات والمرجع والمهارة دون الإجابات.
- `src/data/answerKey.ts`: الحلول والسلم ومعايير العلامات الجزئية؛ يُحمّل بعد التسليم أو بعد دخول المعلم.
- `src/lib/physics.ts`: قوانين السرعة والثقل، قراءة الأعداد العربية والوحدات، والتحقق الجبري من صيغ قانون الثقل المكافئة.
- `src/lib/grading.ts`: تصحيح مستقل لكل فرع، بما فيه المعايير الدلالية الجزئية لأسئلة التفسير.
- `src/lib/persistence.ts`: حفظ المحاولة والمؤقت المعتمد على الطوابع الزمنية.
- `src/lib/report.ts`: إعداد التقرير النصي وتنزيله محلياً.
- `src/components/Figures.tsx`: أربعة رسوم SVG أصلية متجاوبة بإحداثيات ثابتة و`preserveAspectRatio`.
- `src/components/Math.tsx`: عرض المعادلات والوحدات بواسطة KaTeX الحقيقي مع اتجاه LTR.
- `public/audio/`: إشارتا بدء وتسليم WAV أصليتان مولّدتان محلياً؛ يمكن كتمهما.
- `tests/`: اختبارات قوانين الفيزياء والتصحيح والرسوم وحدود العلامات.

## الرسوم وسلّم التصحيح

مخطط المسافة والزمن يستخدم النقاط `(0,0)` و`(4,20)` و`(8,20)` و`(12,60)`؛ يمثّل الأول حركة منتظمة بسرعة 5 m/s، والثاني سكوناً، والثالث حركة منتظمة بسرعة 10 m/s. سهم القوة يبدأ عند `A` على الحامل الأفقي نحو اليمين؛ طوله 180 وحدة SVG، ويقسم إلى ثلاثة أجزاء طول كل منها 60 وحدة، وكل جزء يمثل 5 N، فتكون الشدة 15 N. المسار الثالث متصل من `A` إلى `D` عبر مستقيم ثم قوس ثم مستقيم؛ أطوال الأجزاء 7 m و5 m و8 m **معطاة وليست مقياساً للصورة**.

عند صحة قيمة عددية مع كتابة وحدة خاطئة تُحسم علامة واحدة من ذلك الفرع، ما لم تكن علامة الفرع واحدة. تُقبل الأرقام العربية والفارسية والإنكليزية، وفواصلها العشرية، والوحدات المكافئة. تتحقق صيغة قانون الثقل جبرياً بدلاً من مطابقة نصها، وتُمنح معايير مستقلة للتفسير العلمي. في عداد النتائج يُحتسب الفرع صحيحاً إذا نال علامته كاملة، وتظهر العلامات الجزئية في تفاصيله.
