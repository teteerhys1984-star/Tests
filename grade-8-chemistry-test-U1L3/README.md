# اختبار الكيمياء – الصف الثامن

تطبيق امتحان تفاعلي كامل للصف الثامن، الوحدة الأولى، الدرس الثالث: **صيغة المركّبات الكيميائية**، اعتمادًا على صفحات الكتاب المدرسي **18–23**.

العنوان المحايد المستخدم في الواجهة:

**اختبار الكيمياء – الصف الثامن**

## ما تم بناؤه

- سبعة أسئلة رئيسية أصلية، وليست نسخة من اختبار المستودع ذي الثمانية عشر سؤالًا.
- مجموع العلامات **100** بالضبط، مع علامة صريحة لكل جزء فرعي.
- واجهة عربية RTL، وخط IBM Plex Sans Arabic محلي، وثيم مختبر علمي داكن.
- عرض الصيغ الكيميائية والشحنات والأقواس عبر KaTeX، مع عزل LTR للصيغ.
- تصحيح آلي يدعم الائتمان الجزئي، والتحقق من التعادل الكهربائي، وأبسط نسبة صحيحة.
- مؤقّت تصاعدي HH:MM:SS يعتمد على الطوابع الزمنية، ويستمر بعد التحديث.
- حفظ محلي للاسم والإجابات والسؤال الحالي وحالة المحاولة والوقت.
- أصوات بدء وتسليم محلية مولّدة عبر Web Audio، مع كتم/تفعيل.
- صفحة نتائج مفصلة، وتقرير TXT قابل للتنزيل محليًا بترميز UTF-8.
- مفتاح إجابات للمعلّم خلف كلمة مرور محلية فقط.

## الفحوص

```bash
npx tsc --noEmit
npx vitest run
node scripts/browser-check.mjs
```
