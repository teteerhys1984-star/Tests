# سجل التحقق

تم تنفيذ الفحوص التالية فعليًا في بيئة البناء.

## أوامر نُفّذت

```bash
npm install
npx tsc --noEmit
npx vitest run
npm run build
node scripts/browser-check.mjs
```

## نتائج اختبارات الوحدة

- ملفات الاختبار: 4
- الاختبارات الناجحة: 67
- الاختبارات الفاشلة: 0

تغطي الاختبارات:

- تحليل الصيغ الكيميائية.
- الأُسّ السفلي والأقواس.
- الشحنات الأيونية.
- التعادل الكهربائي.
- أبسط نسبة صحيحة.
- عدّ الذرات.
- التكافؤ المشترك والأيوني.
- التسمية والأرقام الرومانية.
- الائتمان الجزئي.
- اكتمال الإجابات.
- المؤقّت والاستعادة.
- التقرير النصي.
- واجهة البدء والتسليم وبوابة المعلّم.

## نتيجة البناء

نجح `npm run build` وأنتج:

```text
dist/index.html
```

الحجم التقريبي للناتج: 2.6 MB قبل الضغط، و1.5 MB بعد gzip، بسبب تضمين الخطوط وKaTeX محليًا.

## فحص المتصفح

استخدم `scripts/browser-check.mjs` متصفح Chromium عبر Playwright، وشغّل نسخة الإنتاج المقدمة محليًا.

نجحت 30 فحصًا متصفحيًا، منها:

- ظهور العنوان المحايد وسبعة أسئلة.
- عدم وجود مؤقّت قبل البدء.
- التحقق من الاسم الكامل.
- بدء المحاولة وتعطيل التسليم قبل الاكتمال.
- تعبئة الأجزاء الواحد والثلاثين عبر عناصر الواجهة الفعلية.
- تحديث الصفحة أثناء السؤال الرابع واستعادة الإجابات والطابع الزمني.
- إدراج قوسين وجذر متكرر عبر لوحة كتابة الصيغة.
- التسليم الفوري دون مربع تأكيد.
- ظهور النتيجة 100/100 عند الإجابات الصحيحة.
- تنزيل تقرير TXT محلي يحتوي الاسم والعلامات والمعايير والمراجع.
- بدء محاولة جديدة بعد اكتمال السابقة، مع طلب الاسم من جديد.
- رفض كلمة مرور خاطئة للمعلّم، وقبول كلمة المرور المطلوبة.
- ظهور حلول الأسئلة السبعة في مفتاح المعلّم.
- عدم وجود طلبات خارجية.
- عدم وجود أخطاء تشغيل.
- عدم ظهور أوامر LaTeX خام.
- عدم وجود تنزيل للشيفرة أو الأرشيف في واجهة الطالب.

## ملاحظة اسم ملف التقرير

يضبط التطبيق خاصية التنزيل على اسم الطالب، مثل:

```text
تقرير-سمر-شاهين.txt
```

في Chromium headless قد يعيد مشغّل الاختبار اسمًا عامًا مثل `download` عند قراءة `suggestedFilename()` لأسماء الملفات العربية، رغم أن خاصية `download` في الرابط تحمل الاسم العربي الصحيح. تم التحقق مباشرة من خاصية `download` ومن محتوى التقرير الذي جرى تنزيله وحفظه محليًا.

## قيود مقصودة

- حماية مفتاح المعلّم محلية في المتصفح فقط، وليست مصادقة آمنة أو تشفيرًا.
- لا توجد خدمات خارجية، ولا Google Sheets، ولا إرسال لبيانات الطالب.
- لا يُعرض أرشيف المشروع أو الشيفرة داخل واجهة الطالب.
