# اختبار اللغة العربية – الصف الخامس الأساسي | حديقة المعرفة

اختبار رسمي تفاعلي في **قواعد اللغة والإملاء فقط**، يغطي:
- الوحدة الأولى كاملة: السمكة الذهبية (ص 8–9)، بالرأي والرأي الآخر (ص 17–20)، لغتي (ص 28–32)
- الوحدة الثانية: مخترع من بلادي (ص 44–46)، الذكاء الاصطناعي (ص 54–56)

## التوزيع المؤكد
- **30 سؤالًا رئيسيًا** (6 لكل درس × 5 دروس)
- **15 سؤال قواعد + 15 سؤال إملاء**
- **70 فرعًا** قابلًا للتصحيح المستقل
- **100 درجة** بالضبط

جميع الأسئلة والجمل والكلمات **أصلية بالكامل** ولم تُنسخ من الكتاب المدرسي أو من المستودع المرجعي؛ القواعد المختبرة فقط هي المقررة.

## التشغيل
```bash
npm install
npm run dev      # التطوير
npm run build    # بناء الإنتاج إلى dist/
npm run preview  # معاينة البناء
```

## الميزات
- اسم الطالبة إلزامي، والمؤقت (HH:MM:SS) يبدأ عند الضغط على «بدء الاختبار» ويُحفظ عبر التحديث (localStorage).
- لا إجابات ولا درجات أثناء الاختبار؛ التسليم فوري بزر «تسليم الاختبار» دون حوار تأكيد.
- أصوات أصلية عبر Web Audio API مع زر تشغيل/إيقاف.
- تقرير TXT عربي UTF-8 قابل للتنزيل، ومفتاح معلم بكلمة مرور `somer173` (حاجز واجهة فقط، لا مصادقة حقيقية).
- تصميم أنثوي «حديقة المعرفة» باتجاه RTL كامل.
