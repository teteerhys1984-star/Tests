# زهرة المعرفة — اختبار اللغة العربية للصف الخامس الأساسي

**Zahrat al-Ma'rifa — Grade 5 Arabic Grammar & Spelling Examination**

اختبار رسمي كامل في **قواعد اللغة** و**الإملاء** فقط، مبني على خمسة دروس من المنهاج، بواجهة عربية RTL وتصميم زهري أنيق، ومزوّد بمؤقّت تصاعدي، وحفظ تلقائي، وتصحيح بعد التسليم، وتقرير TXT، ودليل معلمة محمي.

---

## 1) التشغيل

```bash
npm install
npm run dev       # خادم التطوير
npm run build     # حزمة الإنتاج في dist/
npm run preview   # معاينة حزمة الإنتاج
```

يتطلب Node.js 18+ (تم التحقق باستخدام Node 20 وVite 7).

فحص الأنواع:

```bash
npx tsc --noEmit
```

> لا تحتاج الخدمة إلى خادم أو قاعدة بيانات أو أي واجهة خارجية. كل شيء يعمل في المتصفح.

---

## 2) النطاق التعليمي

يغطي الاختبار **٥ دروس فقط**، وفي قسمَي **قواعد اللغة** و**الإملاء** فقط. لا يتضمن فهمًا قرائيًّا، ولا مفردات، ولا تواصلًا شفويًّا، ولا تعبيرًا كتابيًّا، ولا خطًّا، ولا استماعًا.

| # | الدرس | الصفحات | القواعد | الإملاء |
|---|---|---|---|---|
| ١ | السمكة الذهبية | ٨–٩ | الجملة وأنواعها: اسمية وفعلية | الهمزة الأولية: القطع والوصل |
| ٢ | بالرأي والرأي الآخر | ١٧–٢٠ | المصدر وعلاقته بفعله | همزة القطع: مواضعها ورسمها |
| ٣ | لغتي | ٢٩–٣٢ | أركان الجملة الفعلية | همزة الوصل في الأفعال والأسماء |
| ٤ | مخترع من بلادي | ٤٤–٤٦ | الجملة الاسمية: المبتدأ والخبر والنعت | الهمزة الأولية: تطبيق وتمييز |
| ٥ | الذكاء الاصطناعي | ٥٤–٥٦ | تحويل الفعلية إلى اسمية والعكس | التاء المبسوطة والمربوطة |

**المرجع المستخدم:** سجل المنهاج، وملفات محتوى الدروس الخمسة، وتدقيقات المصدر، وأقفال المصادر، وتقارير التغطية في المستودع:
`teteerhys1984-star/Interactive-arabic-grade5`.

### حدود المصدر (معلنة صراحةً)

- لم يُستخدم **نص إملاء المعلم غير المطبوع** في درس «مخترع من بلادي» أساسًا لأي سؤال.
- لم تُحوَّل المواد المعلّمة كغير محسومة بصريًّا (مثل بعض صيغ الإكمال في «لغتي» وصيغة فعل مطبوعة في «الذكاء الاصطناعي») إلى إجابات قطعية.
- لم تُضف مفاهيم خارج نطاق القسمين المحددين.
- صفحة كل سؤال مأخوذة من نطاق الدرس الموثّق؛ وتُستخدم الصفحات الداخلية (١٨، ٢٠، ٣٠، ٣١، ٣٢، ٥٥، ٥٦) لتمارين التقويم كما وردت في أقفال المصادر.

## 3) بنية الامتحان

- **٣٠ سؤالًا رئيسًا** بالضبط، ستة أسئلة لكل درس (٣ قواعد + ٣ إملاء).
- **٨٠ فرعًا** قابلًا للتقييم، لكل فرع درجة مستقلة.
- **١٠٠ درجة** بالضبط: ٢٠ لكل درس (١٠ قواعد + ١٠ إملاء)، و٥٠ لقواعد اللغة و٥٠ للإملاء على مستوى الاختبار.
- **توزيع الصعوبة:** ٩ أساسي (٣٠٪) — ١٤ متوسط (٤٧٪) — ٧ متقدم (٢٣٪)، والمتقدمة تطبيق وتعليل داخل النطاق.
- ترتيب الأسئلة **مختلط** ولا يتبع ترتيب الكتاب، مع مرجع داخلي دقيق لكل سؤال.
- أنواع الأسئلة: اختيار من متعدد، اختيار متعدد، إكمال/كتابة، تصنيف جمل وهمزات وتاءات، تعيين مبتدأ/خبر/فاعل/مفعول، مطابقة المصدر بفعله، تحويل الجمل، تصحيح كتابة، وتعليل.

### التصحيح

- الاختيار المفرد: تُمنح درجة الفرع كاملة للإجابة الصحيحة فقط.
- الاختيار المتعدد: تُشترط **جميع** الاختيارات الصحيحة دون أي اختيار خاطئ؛ لا درجة جزئية داخل الفرع نفسه.
- الكتابة: تُقبل الإجابة دون تشكيل (تطبيع الهمزات/التشكيل)، مع الحفاظ على الحرف الذي تختبره القاعدة.
- الفراغ غير المجاب يُحتسب «غير مجاب»، ويظهر منفصلًا عن «الخطأ» في النتائج.
- الدرجات الجزئية تتحقق عبر الفروع المستقلة داخل السؤال.

---

## 4) سلوك الاختبار

- **الاسم إلزامي**، ولا يبدأ المؤقّت إلا بعد الضغط على «ابدئي الاختبار».
- **مؤقّت تصاعدي** بصيغة `HH:MM:SS`، محسوب من طوابع زمنية (`startedAt` / `submittedAt`) لا من عدّاد متقطع.
- **حفظ تلقائي** في `localStorage` للاسم ومعرّف المحاولة ووقت البدء والإجابات والسؤال الحالي.
- **استعادة بعد التحديث:** لا تبدأ محاولة جديدة، ويعود الاختبار بالمؤقّت والإجابات نفسها.
- **من دون إجابات أو تلميحات أو تصحيح فوري أو درجة** خلال الاختبار.
- **«تسليم الاختبار»** بلفظها الدقيق، وتبقى معطّلة حتى تُجاب كل الفروع.
- عند التسليم: **تسليم فوري دون أي حوار تأكيد**، ويُعرض فورًا:
  - درجات وتقرير كامل، ومستوى أداء، وزمن مستغرق.
  - تفصيل كل الأسئلة والفروع: إجابة الطالبة، الإجابة الصحيحة، الحالة، الدرجة/الدرجة القصوى، التفسير، والمرجع الداخلي.
  - جدول لكل درس (قواعد/إملاء/المجموع)، والدرجة العامة في القسمين.
  - خريطة مهارات تحتاج إلى مراجعة بنسب دقيقة.
- **إعادة الاختبار** بعد التسليم فقط، مع طلب الاسم مجددًا ومسح بيانات المحاولة السابقة.

---

## 5) التقرير ودليل المعلمة

- **تقرير TXT** يُولَّد محليًّا بترميز UTF-8 (مع BOM لعرض العربية في Notepad)، باسم:
  `Arabic_Grade5_Grammar_Spelling_[StudentName].txt`
  ويُحمَّل تلقائيًّا بعد التسليم، مع زر نسخة احتياطية **«تحميل التقرير TXT»** في النتائج. يوجد في التقرير كل بيانات الطالبة والزمن والدرجات وتفصيل الأسئلة ١–٣٠ وفروعها والتفسيرات والمراجع الداخلية.
- **دليل المعلمة**: يُفتح بكلمة المرور `somer173`، ويعرض الإجابات والتفسيرات وروبرِك التصحيح والأخطاء الشائعة والمرجع الداخلي (الوحدة/الدرس/الصفحة/القسم/المهارة) وتوزيع الدرجات. الحماية **حاجز وصول تعليمي في جهة العميل فقط** وليست مصادقة أمنية.

---

## 6) الصوت والتصميم

- مؤثران أصليان يُولَّدان عبر Web Audio API (لا ملفات أو روابط خارجية): نغمة بداية ونغمة تسليم، مع زر تشغيل/إيقاف.
- هوية **«زهرة المعرفة»**: وردي باستيلي، خزامي، خوخي، كريمي، زخارف نباتية، وفراشات دقيقة، بطاقات مستديرة وظلال ناعمة.
- خطوط عربية: **Tajawal** للنصوص و**Amiri** للعناوين، مع بدائل نظامية موثوقة. الأرقام العربية الهندية مستخدمة في العرض، والمؤقّت بالصيغة المطلوبة `HH:MM:SS`.
- تصميم متجاوب (سطح مكتب/جهاز لوحي/هاتف)، وواجهة عربية RTL بالكامل.

## 8) التحقق المنفَّذ

- `npx tsc --noEmit` — بلا أخطاء.
- `npm run build` — بناء إنتاجي ناجح.
- `scripts/qa.ts`: عدد الأسئلة ٣٠، الفروع ٨٠، الدرجات ١٠٠، ٦ أسئلة و٢٠ درجة لكل درس، ٣+٣ قواعد/إملاء، صحة صيغ الأسئلة، التوزيع ٩/١٤/٧، حسابات الدرجات والجزئيات وغير المجاب، وترميز التقرير.
- `scripts/render-qa.tsx`: عرض كل الشاشات، وعدم تسريب الإجابات في شاشة الاختبار، وظهور مفتاح المعلم بعد كلمة المرور.
- `scripts/browser-qa.ts` (Chromium/Playwright): التحقق من الاسم الإلزامي، بدء المؤقّت، الحفظ التلقائي، استعادة المحاولة بعد التحديث مع استمرار المؤقّت، تعطيل التسليم قبل الاكتمال، التسليم الفوري دون تأكيد، ملف TXT، صفحة النتائج والتفصيل، بوابة المعلمة (كلمة خاطئة/صحيحة)، وإعادة الاختبار.

**حدود التحقق:** لم تُجرَّب الملفات الصوتية بأذن بشرية في بيئة الاختبار الآلية؛ يُنشئ التشغيل Web Audio فقط ولا يعتمد على الشبكة. الشيخوخة/التصميم تم فحصهما بلقطات شاشة سطح المكتب والهاتف. حاجز المعلمة ليس أمنًا حقيقيًّا بحكم أنه يعمل في المتصفح.

---

## 9) الخصوصية

لا يوجد خادم ولا قاعدة بيانات ولا تحليلات. تُخزَّن المحاولة في `localStorage` داخل المتصفح فقط، ويُولَّد التقرير محليًّا. لا تُرسل بيانات الطالبة إلى أي جهة خارجية.
