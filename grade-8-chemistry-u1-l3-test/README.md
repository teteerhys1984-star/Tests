# Chemistry U1 L3 Test

تطبيق اختبار تفاعلي لمنهاج الكيمياء — الصف الثامن، الوحدة الأولى، الدرس الثالث (**صيغة المركّبات الكيميائية**، الصفحات **18–23**)، منشور ضمن منصة الاختبارات تحت المعرّف:

`grade-8-chemistry-u1-l3-test`

## المواصفات الرئيسية

- **العنوان المعروض:** `Chemistry U1 L3 Test` (مع وصف الدرس بالعربية RTL).
- **البنية والدرجات:** 7 أسئلة رئيسية أصلية (`[10, 15, 15, 20, 15, 10, 15]`)، 31 جزءًا فرعيًا، المجموع **100 علامة**.
- **المحرك العلمي:** تحليل الصيغ والأيونات والأقواس وعدّ الذرات والتعادل الكهربائي وأبسط نسبة، وعرض KaTeX محلي بالكامل بدون مصادر خارجية.
- **مراجعة قبل التسليم:** زر التسليم متاح دائمًا ويفتح شاشة مراجعة تعرض كل الأسئلة والأجزاء مع تنبيه واضح للأجزاء غير المكتملة وروابط انتقال مباشر وتأكيد صريح قبل التسليم.
- **التسليم إلى Google Sheets + التقرير المحلي:** إرسال آلي في الخلفية عبر `POST` (`text/plain;charset=utf-8`) إلى Google Apps Script مع 3 محاولات وإعادة تلقائية من `pending:<EXAM_ID>:<attemptId>` وإيصال استلام وزر إعادة إرسال يدوي وتنزيل تقرير نصي UTF-8 محلي في جميع الحالات.
- **منطقة المعلّم:** مفتاح إجابات كامل خلف كلمة مرور محلية في المتصفح فقط (`somer173`).

## الأوامر

```bash
npm install
npm run typecheck
npm test
npm run build
```

## ملفات المشروع

- `src/config.ts` — ثوابت الهوية ومفاتيح التخزين وعنوان الإرسال.
- `src/data/exam.ts` — بيانات الأسئلة السبعة والأجزاء الـ 31 ومراجع الكتاب.
- `src/lib/{chemistry,grading,report,session,submit,sound,types}.ts` — المنطق العلمي والتصحيح والحفظ والإرسال.
- `src/components/{Entry,ExamView,AnswerControl,Results,TeacherKey,Layout,Molecule,Chem}.tsx` — واجهة الطالب والمراجعة والنتائج والمعلّم.
- `scripts/browser-check.mjs` — سكربت تحقق شامل عبر Playwright (مع حجب طلبات الشبكة الحقيقية نحو Google Sheets).
