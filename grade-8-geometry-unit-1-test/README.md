# Grade 8 Geometry Unit 1 Test

اختبار الهندسة للصف الثامن، الفصل الأول: متوازيات الأضلاع والانسحاب. مصدر المحتوى والتصميم هو المجلد `../grade-8-geometry-test-Unit 1` غير المعدّل. التطبيق مستقل، ويحافظ على الأسئلة والأشكال والأسلوب الأصلي؛ الإضافات هي المراجعة والتسليم وبيان حالة الإرسال ونحوها.

## التشغيل والتحقق

```sh
npm ci
npm run dev
npx tsc --noEmit
npx vitest run
npm run build
python3 tests/test_index.py  # من جذر المستودع: python3 grade-8-geometry-unit-1-test/tests/test_index.py
```

`dist/index.html` هو ملف النشر المستقل. ملفات الأسئلة والرسوم هي `src/exam/questions.tsx` و`src/components/figures.tsx` و`src/components/geo/Figure.tsx`؛ التنسيق الأصلي في `src/index.css`. يحتوي الاختبار ٧ أسئلة، ٣٣ فرعاً و١٠٠ علامة: ١٥ لكل من س١–س٦ و١٠ لس٧. انظر توزيع الموضوعات ونتائج التحقق في [VERIFICATION.md](VERIFICATION.md).

## المحاولة والمنطقة التعليمية

يبدأ الطالب باسمه، وتُحفظ الجلسة تلقائياً تحت `grade-8-geometry-unit-1-test/session/v1`. يمكن مراجعة الإجابات وتعديلها قبل التسليم، بما في ذلك الفروع المتروكة. النتائج تتضمن الإجابات والشرح والرصد الجزئي وتقرير TXT؛ وتبدأ المحاولة الجديدة بمعرّف وإجابات مستقلين. عند ترتيب الخطوات يجب تحريكها أو اعتماد الترتيب المعروض صراحةً، حتى لا يُحتسب ترتيب لم يختره الطالب إجابةً.

منطقة المعلّم `#/teacher` بكلمة المرور المطلوبة `somer173` تشمل سلم الإجابات والحلول وعلامات الفروع وتفاصيل أداء المحاولة المسلّمة الموجودة على الجهاز. **هذه بوابة عميل فقط وليست حماية أمنية:** الكلمة والحلول موجودة في صفحة التطبيق ويمكن استخراجها.

## الإرسال والخصوصية

بعد التأكيد تُرسل النتيجة إلى إعداد Google Sheets نفسه المستخدم في `grade5-math-unit1`. لكل محاولة `attemptId` ثابت وفريد؛ تُحفظ نسخة الإرسال قبل البدء تحت `pending:grade-8-geometry-unit-1-test:<attemptId>`، وتُحذف عند التأكيد وتُعاد عند فتح الصفحة. ثلاث محاولات بفاصل ثانيتين ثم خمس ثوانٍ، ومهلة ٣٠ ثانية لكل محاولة. تظهر الحالة وزر إعادة الإرسال؛ النتيجة وتنزيل التقرير لا يتوقفان على نجاح الشبكة. البيانات المعلقة محفوظة محلياً دون تشفير، وقد لا تعمل الاستعادة إذا كان التخزين محظوراً أو ممتلئاً. الاختبارات تعترض الشبكة ولا ترسل بيانات فعلية.

## التصحيحات التقنية في النسخة الجديدة

- المصدر يهيّئ إجابة الترتيب آلياً عند البدء، فيمنح نقاطاً لترتيب لم يؤكده الطالب. لم نغيّر الترتيب المعروض ولا مفتاح التصحيح؛ لم يعد يُحتسب إلا بعد تحريك الخطوات أو اعتمادها.
- كانت بعض الإجابات النموذجية والإجابات المحددة تُعرض كنص LaTeX خام في النتيجة ومنطقة المعلّم. تعرضها النسخة الجديدة بـ KaTeX مثل نص السؤال، وفي TXT تُحوّل صيغ الكسور والجذور وأسهم المقابلة إلى نص مفهوم بدلاً من إسقاط أوامرها. لم تتغيّر أي إجابة أو علامة.
- إتاحة مراجعة الفروع غير المجابة والتسليم بعد التأكيد، بدلاً من حظر التسليم حتى اكتمالها، وإزالة العبارة القديمة التي تنفي الإرسال الخارجي لأنها لم تعد صحيحة.

التغييرات المشتركة محصورة بتسجيل الاختبار وتاريخ إضافته، ودعم تاريخ ISO في مولّد الفهرس، واستثناء مجلد المصدر من مساري البناء المحلي وGitHub Actions. لم يُعدّل خط Cairo أو بوابة المنصة.
