## 2. المزايا التقنية والتربوية

- **الخط العربي الإلزامي محلياً**: تضمين خط `IBM Plex Sans Arabic` محلياً عبر `@fontsource/ibm-plex-sans-arabic` دون الاعتماد على اتصال الإنترنت.
- **عرض الرموز الرياضية الحقيقية (KaTeX)**: عرض جميع الصيغ والرموز والزوايا والأزواج المرتبة عبر مكتبة `KaTeX` داخل حاويات معزولة باتجاه LTR (`unicode-bidi: isolate`).
- **لوحة الرموز الرياضية التفاعلية**: تتضمن الأرقام `0–9`، والعمليات `+`، `−`، `×`، `÷`، `=`، والأقواس `( )`، ومحرّر كسر تفاعلي حقيقي ببسط ومقام منفصلين، مع الإدراج المباشر في موضع المؤشر.
- **رسوم وأدوات هندسية تفاعلية (SVG)**:
  - شبكة إحداثيات للقراءة والتعيين التفاعلي للنقاط وتتبع المسارات.
  - تمثيلات بيانية بالخطوط مع الجداول المرافقة.
  - مستقيم أعداد لتحديد نقطة المنتصف والتقريب.
  - منقلة هندسية دقيقة للقراءة والإنشاء التفاعلي للشعاع مع قبول هامش لمس مناسب للموبايل.
  - أشكال هندسية دقيقة لمتوازي الأضلاع والمعيّن والزوايا والأشكال المركبة.
- **مؤقت تصاعدي وحفظ تلقائي**: مؤقت بصيغة `HH:MM:SS` يعتمد على الطوابع الزمنية الحقيقية (`Timestamps`) ولا يبدأ إلا بعد إدخال اسم الطالبة والضغط على زر «بدء الاختبار»، مع حفظ تلقائي كامل في `localStorage`.
- **تسليم فوري من دون نوافذ تأكيد**: يبقى زر **«تسليم الاختبار»** معطلاً حتى الإجابة عن جميع الفروع المطلوبة، وعند النقر عليه ينتقل فوراً إلى صفحة النتائج التفصيلية مع إمكانية تنزيل تقرير `TXT` بترميز `UTF-8`.
- **لوحة المعلّم**: محمية بكلمة المرور `somer173` كوسيلة إخفاء للواجهة، وتعرض جميع الأسئلة والإجابات النموذجية وخطوات الحل وتوزيع العلامات ومراجع الدروس والصفحات.

## 3. التشغيل والفحص والبناء

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# تشغيل اختبارات الوحدات (Unit Tests) لمنطق التصحيح والدقة الرياضية
npx tsx src/tests/exam.test.ts

# فحص الأنواع (TypeScript Typecheck)
npx tsc --noEmit

# بناء نسخة الإنتاج
npm run build
```
