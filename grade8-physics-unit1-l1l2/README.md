# اختبار الفيزياء — الصف الثامن — الوحدة الأولى (الدرسان الأول والثاني)

اختبار إلكتروني تفاعلي عربي (RTL) يغطي **الدرس الأول والدرس الثاني من الوحدة الأولى فقط**،
مبنيّاً على محتوى المستودع المرجعي
[`Interactive-Physics-Grade8`](https://github.com/johntaylorjt1876-cell/Interactive-Physics-Grade8)
(الفرع الصحيح: `johntaylorjt8870-cell/Interactive-Physics-Grade8`).

- معرّف الاختبار: `EXAM_ID = grade8-physics-unit1-l1l2`
- مجموع العلامات: **100** (10 أسئلة رئيسية · 49 فرعاً مُقوّماً)
- التصحيح: تلقائي بالكامل داخل المتصفح
- الإرسال: نفس عقد الاختبار المرجعي `grade5-math-unit1` إلى Google Apps Script نفسه

## «الصفحة الأولى: بطاقة البدء» في التطبيق

1. صفحة ترحيب + شرح مختصر + إدخال اسم الطالب.
2. صفحة الأسئلة (سؤال واحد في كل شاشة، فهرس جانبي، مؤقّت تصاعدي، شريط تقدّم).
3. صفحة «مراجعة الإجابات» قبل التسليم (التسليم معطّل حتى تُجاب كل الفروع).
4. صفحة النتيجة: الدرجة والنسبة وتوزيع العلامات والمراجعة التفصيلية بالحلول.
5. تقرير TXT يُنزَّل تلقائياً عند التسليم، ويبقى قابلاً للتنزيل من صفحة النتيجة.

## نطاق المحتوى (من المستودع المرجعي فقط)

| المصدر في المستودع المرجعي | ما استُعمل منه |
| --- | --- |
| `index.html` (فهرس الوحدة الأولى) | تحديد الوحدة الأولى «الحركة والقوى»، والدرس الأول ص 55–62، والدرس الثاني ص 63–70 |
| `src/lesson-content.js` | الدرس الأول: العناصر الأربعة للقوة، مقياس الرسم، تعريف القوى المتلاقية، قاعدة متوازي الأضلاع، الحالات الخاصة، القوتان المتعامدتان، تحليل القوة، المستوى المائل، دفتر الطالب |
| `src/lesson-1-practice-data.js` | المسألة الأولى ص 62 (12 N و15 N) والمسألة الثانية (30 N و40 N)، حسابات المقياس |
| `src/lesson-test-data.js` | صياغات أسئلة الكتاب في الدرس الأول (12 N و16 N، 40 N و50 N، القوة الموازِنة، تحليل القوة) |
| `src/lesson-2-content.js` | الدرس الثاني: تعريف القوى المتوازية، تجربة المسطرة، عناصر المحصلة بجهة واحدة وبجهتين متعاكستين، تساوي الجداءين، التطبيقات المحلولة (20/30 N و200/300 N) |
| `src/lesson-2-practice-data.js` · `src/lesson-2-test-data.js` | أسئلة ص 70 (3 N و4 N بجهة واحدة، 30 و120 سم، 12/8 N، 55/15 N)، حالات التساوي والمنتصف |

لم يُستعمل أي محتوى من أسئلة الوحدة (ص 71–72) ولا من الوحدة الثانية.

## السكربتات

```bash
npm ci
npm run typecheck   # tsc --noEmit
npm test            # اختبارات التصحيح والحمولة والإرسال وسير العمل (بلا شبكة حقيقية)
npm run build       # ناتج single-file في dist/index.html
```

> `npm test` يستعمل خادماً بديلاً (fetch وهمي) وساعة وهمية؛ **لا يجري أي اتصال حقيقي بـ Google Apps Script**
> ولا يُكتب أي شيء في Google Sheets أثناء الاختبارات.

## الإرسال إلى معلّمك (Google Sheets)

- `SHEETS_URL` و`SHEETS_TOKEN` مأخوذان حرفياً من `grade5-math-unit1/src/config.ts`.
- `POST` بنوع `text/plain;charset=utf-8`، و3 محاولات بفاصل 2 ثم 5 ثوانٍ، ومهلة 30 ثانية للمحاولة.
- عند فشل كل المحاولات تُحفظ الحمولة في `localStorage` تحت `pending:<EXAM_ID>:<attemptId>`،
  وتُعاد بصمت عند فتح الاختبار لاحقاً، ولا تُرسَل المحاولة نفسها مرتين.
- حمولة الإرسال تطابق عقد المرجع حرفياً:
  `token, attemptId, examId, examTitle, studentName, startAt, submitAt, elapsedSec, summary, lessons, details, reportText`
  مع `summary.gradeLabel` (يُرسَل للمعلّم فقط ولا يظهر للطالب ولا في تقرير TXT).
