# Tests

منصة اختبارات إلكترونية تفاعلية للصفوف من الأول إلى التاسع. كل اختبار مجلد
مستقل يُنشر كملف HTML واحد مكتفٍ بذاته.

## البنية

```
<exam-folder>/     مجلد اختبار واحد (يُنشر dist/index.html منه)
landing/           تصميم ومولّد الصفحة الرئيسية (الصفوف ← المواد ← الاختبارات)
.github/workflows/deploy.yml   يبني كل الاختبارات ثم يولّد الفهرس وينشره
```

الصفحة الرئيسية (الفهرس) تُولَّد تلقائيًا من مجلد `landing/`، وتعرض الاختبارات
في ثلاث خطوات: **الصف ← المادة ← الاختبار**. قاعدة ظهور المواد وتفاصيل
التصميم موثّقة في [`landing/README.md`](landing/README.md):

* العربية والرياضيات والإنجليزية: الصفوف 1 – 9
* الفيزياء والكيمياء: الصفوف 7 – 9 فقط

## التشغيل المحلي

```bash
bash landing/scripts/build-exams.sh   # بناء كل الاختبارات وتجميعها في _site
python3 landing/generate.py _site     # توليد الصفحة الرئيسية
python3 landing/tests/test_generate.py
python3 -m http.server 8080 --directory _site
```
