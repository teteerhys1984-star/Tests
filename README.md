# Tests

منصة اختبارات إلكترونية تفاعلية للصفوف من الأول إلى التاسع. كل اختبار مجلد
مستقل يُنشر كملف HTML واحد مكتفٍ بذاته.

## البنية

```
<exam-folder>/     مجلد اختبار واحد (يُنشر dist/index.html منه)
landing/           تصميم ومولّد الصفحة الرئيسية (الصفوف ← الفصول ← المواد ← الاختبارات)
.github/workflows/deploy.yml   يبني كل الاختبارات ثم يولّد الفهرس وينشره
```

الصفحة الرئيسية (الفهرس) تُولَّد تلقائيًا من مجلد `landing/`، وتعرض الاختبارات
في أربع خطوات: **الصف ← الفصل الدراسي ← المادة ← الاختبار**. السنة الدراسية
فصلان، وكل الاختبارات الحالية مصنّفة تحت الفصل الأول؛ الفصل الثاني مدعوم في
البنية ويمكن إضافة اختباراته مستقبلًا دون تعديل نظام الفهرس. قاعدة ظهور المواد
وتفاصيل التصميم موثّقة في [`landing/README.md`](landing/README.md):

* العربية والرياضيات والإنجليزية: الصفوف 1 – 9
* الفيزياء والكيمياء: الصفوف 7 – 9 فقط

## بوابة الدخول

الصفحة الرئيسية للمنصة (`/Tests/`) تبدأ ببوابة كلمة مرور بسيطة، فلا تظهر قائمة
الصفوف والفصول والمواد إلا بعد إدخالها. كلمة المرور الافتراضية `somer2026`،
والحالة تُحفظ في `sessionStorage` حتى إغلاق تبويب المتصفح.

هذه **حاجز تجميلي فقط** وليست حماية أمنية: كلمة المرور (بصمتها) تُنشر مع صفحة
HTML، ويمكن تجاوزها تقنيًا. أما صفحات الاختبارات نفسها فهي **غير محجوبة**، وتبقى
روابط الطلاب المباشرة تعمل كما هي. التفاصيل وطريقة تغيير الكلمة:
[`landing/README.md`](landing/README.md).

## التشغيل المحلي

```bash
bash landing/scripts/build-exams.sh   # بناء كل الاختبارات وتجميعها في _site
python3 landing/generate.py _site     # توليد الصفحة الرئيسية
python3 landing/tests/test_generate.py
node landing/tests/gate.test.mjs      # سلوك بوابة الدخول
python3 landing/scripts/verify-site.py _site
python3 -m http.server 8080 --directory _site
```
