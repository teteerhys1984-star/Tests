# اختبار اللغة العربية — الصف الخامس — النموذج الثاني

النموذج الثاني المستقل من اختبار اللغة العربية للصف الخامس الأساسي: **الوحدة الأولى
كاملة** (السمكة الذهبية، بالرأي والرأي الآخر، لغتي) و**الدرسان الأول والثاني من
الوحدة الثانية** (مخترع من بلادي، الذكاء الاصطناعي).

| البند | القيمة |
|---|---|
| المجلد | `grade5-arabic-u1-u2-l1l2-pattern2` |
| `EXAM_ID` | `grade5-arabic-u1-u2-l1l2-pattern2` |
| الرابط | `/grade5-arabic-u1-u2-l1l2-pattern2/` |
| الأسئلة الرئيسية | 15 |
| الفروع | 45 (3 لكل سؤال) |
| مجموع العلامات | 100 (35 فرعاً × 2 + 10 فروع × 3) |
| الدروس | 5 (٣ أسئلة لكل درس) |
| التقدير | ممتاز 95 · جيد جداً 85 · جيد 75 · مقبول 65 · ضعيف 50 · يحتاج إلى دعم |

> **استقلال تام عن النموذج الأول** `grade5-arabic-u1-u2-l1l2`: معرّف مختلف، وجلسة
> محاولة مشتقة من `EXAM_ID` (`exam:<EXAM_ID>:v1`)، ونتائج معلّقة تحت
> `pending:<EXAM_ID>:<attemptId>`، و`attemptId` جديد لكل محاولة، وسجلات منفصلة في
> Google Sheets، ورابط مستقل في الفهرس. الملفات المشتركة الأخرى (مولّد الفهرس
> `landing/`، وملف النشر `.github/workflows/deploy.yml`، والاختبارات الأخرى) لم
> تُعدّل إطلاقاً.

## التشغيل

```bash
npm ci
npm run typecheck          # tsc --noEmit
npm test                   # كل مجموعات الاختبار (بيانات + إرسال + تدفّق الواجهة)
npm run test:data          # البيانات والتصحيح والتقرير فقط
npm run test:independence  # فحص الاستقلالية عن النموذج الأول والمرجع
npm run build              # ملف HTML واحد مكتفٍ بذاته في dist/
```

## الإرسال إلى Google Sheets

عقد الإرسال مطابق للاختبار المرجعي `grade5-math-unit1` (وكما طبّقه النموذج الأول):

* حمولة من 12 حقلاً: `token, attemptId, examId, examTitle, studentName, startAt,
  submitAt, elapsedSec, summary(11), lessons, details, reportText`.
* `POST` بنوع محتوى `text/plain;charset=utf-8` (تفادي preflight في Apps Script).
* 3 محاولات: نجاح فوري، ثم بعد 2 ثانية، ثم بعد 5 ثوانٍ، ومهلة 30 ثانية للمحاولة.
* `attemptId` فريد لكل محاولة ويُعاد استخدامه عند إعادة إرسال المحاولة نفسها؛
  الخادم يتجاهل التكرار (`duplicate: true` يُعدّ نجاحاً).
* عند فشل كل المحاولات تُحفظ الحمولة في `localStorage` وتُعاد تلقائياً عند فتح
  الاختبار، مع زر مستقل «إعادة إرسال النتيجة».
* فشل الإرسال **لا يمنع** عرض النتيجة ولا تنزيل التقرير.

`SHEETS_URL` و`SHEETS_TOKEN` مأخوذان حرفياً من الاختبار المرجعي ولم يتغيّرا.

## الاختبارات

| الملف | ما يفحصه |
|---|---|
| `tests/data.test.ts` | مطابقة كاملة لخط الأساس الأصلي (`tests/fixtures/baseline.json`)، الحالات الكاملة/الفارغة/الخاطئة/المختلطة/الجزئية، ثبات النتائج (`expected-grading.json`)، عقد التقرير، تدقيق لغوي آلي، سلّم التقدير |
| `tests/submit.test.ts` | عقد الحمولة، الإعدادات، 3 محاولات، التأخيران والمهلة، التخزين والاستعادة، منع التكرار، وعزل مفاتيح الاختبارات الأخرى (خادم وهمي فقط) |
| `tests/workflow.test.tsx` | تدفّق الواجهة كاملاً في jsdom: بدء، مفتاح المعلم، 45 إجابة، تسليم بلا شبكة، تنزيل التقرير، إعادة الإرسال، إعادة التحميل بلا تكرار |
| `tests/check-independence.mjs` | استقلالية المعرّفات ومفاتيح التخزين وعدم تأثّر بقية المشروع |

لا يتصل أي اختبار بالشبكة الحقيقية: يتم اعتراض `fetch` بخادم وهمي.

## خط الأساس والتدقيق

خط الأساس في `tests/fixtures/baseline.json` مستخرج من ملفات المجلد الأصلي
`Arabic_Grade_5_U1 a&L1L2U2 Pattern2` **قبل أي تعديل** (بصمة `src/data/exam.ts`:
`8d8a5cef…`)، ولا يُعاد توليده من الشيفرة المعدّلة. لم تتغيّر أي إجابة صحيحة ولا
أي علامة ولا أي ترتيب سؤال أو فرع.
