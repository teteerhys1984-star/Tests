# اختبار الفيزياء — الصف السابع — النموذج A

اختبار تفاعلي عربي (RTL) لمادة الفيزياء، الصف السابع، يغطي حصراً **الدرس الأول: الحركة والسكون (ص 3–16)** و**الدرس الثاني: القوة والحركة (ص 17–28)** من الوحدة الأولى، وفق محتوى مستودع المنهاج `calesteer-create/Physics_Chemistry_7th`.

## التشغيل

```bash
npm install
npm run dev        # وضع التطوير
npm run typecheck  # فحص TypeScript
npm test           # الاختبارات البرمجية (vitest)
npm run build      # بناء ملف واحد dist/index.html (الخطوط و KaTeX مضمّنة محلياً)
```

## البنية

- `src/data/questions.ts` — الأسئلة العشرة (10 × 10 = 100) مع مفتاح الإجابة، معايير التصحيح النصية، النماذج، المراجع، التفسيرات وخطوات الحل.
- `src/data/graph.ts` — بيانات مخطط المسافة/الزمن (مصدر واحد للحساب والرسم).
- `src/data/teacher.ts` — كلمة مرور منطقة المعلم، سياسة التصحيح، مصادر الرسوم.
- `src/lib/grading.ts` — منطق التصحيح والعلامات الجزئية (مفصول تماماً عن الواجهة).
- `src/lib/normalize.ts` — تطبيع النص العربي وقراءة الأعداد (أرقام عربية، تعبيرات حسابية، وحدات).
- `src/lib/report.ts` — توليد تقرير TXT بترميز UTF-8.
- `src/lib/storage.ts` — الحفظ والاستعادة بـ localStorage (الاسم، الإجابات، السؤال الحالي، وقت البدء، الحالة).
- `src/lib/audio.ts` — صوتا البدء والتسليم مولّدان محلياً بـ Web Audio.
- `src/components/diagrams.tsx` — الرسوم الفيزيائية SVG (المسارات، شعاع القوة بمقياس 1 cm ↔ 10 N، خيارات تمثيل القوة، مخطط المسافة والزمن).
- `src/components/*` — شاشات البداية والاختبار والنتائج ومنطقة المعلم والتذييل.
- `src/tests/` — اختبارات vitest لبنية الاختبار، صحة الحسابات، اتساق المخطط، ومنطق التصحيح.

## قواعد الاختبار

- المؤقت تصاعدي (HH:MM:SS) يعتمد على timestamps ويبدأ بعد الضغط على «بدء الاختبار» ويصمد أمام التحديث.
- زر «تسليم الاختبار» لا يعمل قبل إكمال جميع الفروع، ويسلّم فوراً دون تأكيد.
- لا تُعرض الإجابات النموذجية ولا العلامات قبل التسليم.
- الإجابات النصية تُصحَّح آلياً بمعايير مرادفات مع علامات جزئية؛ التعويض الصحيح يُمنح حتى مع خطأ حسابي لاحق، وعلامة الوحدة مستقلة.

## منطقة المعلم

رابط «منطقة المعلم» في التذييل، كلمة المرور: `somer173`. الحماية client-side فقط (واجهة وليست نظام مصادقة ولا تشفيراً)؛ تتضمن مفتاح الإجابات، سلم التصحيح والعلامات الجزئية، المراجع، خطوات الحل، ومصادر الرسوم.
